# Task Log Redirect

All historical and upcoming RPA optimization tasks now live inside `.tasks/`:
- `current.yaml` — active work in progress.
- `backlog.yaml` — prioritized queue (RPA logging, Supabase readiness, config hardening, pagination, UX fixes).
- `done.yaml` — completed efforts with timestamps and acceptance-test references.

Use those YAML files to track execution; this Markdown file remains only as a pointer for backward compatibility.
